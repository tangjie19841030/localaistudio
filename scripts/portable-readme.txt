Local AI UI Studio 便携试用包
================================

【快速开始】
1. 解压本文件夹到任意位置（不要放中文路径以外的盘符限制——支持中文路径）
2. 双击「START-PORTABLE.bat」
3. 浏览器自动打开 http://localhost:5173

无需安装 Node.js / pnpm / 任何运行时，全部自带。

【AI 模型配置】
默认 mock 模式（内置演示响应，不联网）。
想接真实模型：打开页面 → 顶栏「设置」→
  - openai-compat：填 Base URL / 模型名 / API Key（任何 OpenAI 兼容端点）
  - ollama：本机 Ollama（默认 http://127.0.0.1:11434）
API Key 只保存在本机 data/settings.json，不会上传。

【包含什么】
- app\          完整源码（服务端 + 前端 + 组件库 + Schema 引擎）
- runtime\      自带 node.exe 与 pnpm（离线可用）
- data\         空项目目录 + 演示模板（无任何隐私数据）
- START-PORTABLE.bat  一键启动（自带探活 + 自动开浏览器）
- start-studio.bat  停止/启动管理脚本（stop 参数清理端口）

【试用流程建议】
1. 新建项目 → 填写需求（或选一个起始模板）
2. 左侧 AI 对话：描述想要的页面 → 确认变更计划
3. 预览里点选组件 → 右侧改属性；或继续对话局部修改
4. 底部坞「截图检查」→ 三视口截图 + 自动发现问题 → 发给 AI 修复
5. 「Diff」页签 → 生成代码 → 「项目预览」→ 「导出 zip」
   导出的 React 工程可独立安装、构建、二次开发

【常见问题】
- 端口被占用：运行 启动便携版.bat stop 清理后再启动
- 生成依赖安装慢：导出的项目首次预览需装依赖（离线优先，在线兜底）
- 数据在哪：所有项目数据保存在 data\projects\，删除即清空

【数据与隐私】
- 本包不含任何 API Key 或用户数据
- 除你主动配置的外部模型端点外，全部计算在本机完成
