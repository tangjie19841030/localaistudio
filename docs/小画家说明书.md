# 小画家说明书

> 这是一个画画软件。你说话，电脑帮你把网页画出来。

---

## 一、怎么打开它

1. 找到爸爸或者妈妈。
2. 让他们点一下那个叫 **start-studio** 的图标（一个会闪黑框框的小窗户）。
3. 等一等，电脑会自己打开一个网页。
4. 你会看到三个大格子：**左边**放零件盒子，**中间**是你的画纸，**右边**放调颜色的地方。

如果网页没有自己蹦出来，就喊大人来帮忙。

---

## 二、先做一个新的画本

1. 点蓝色的 **新建项目** 按钮。
2. 给你的画本起一个名字，比如"我的恐龙乐园"。
3. 下面有 **起始模板**，就像美术课发的半成品涂色纸——你可以选一张，也可以不选。
4. 点最下面那个确认的按钮。
5. 你的画本打开啦！

**想看看以前画的？** 回到最开始的列表，点一下你之前的名字就行。

---

## 三、让电脑帮你画（最好玩的部分）

中间下面有一个输入框，把你想画的告诉它，然后按回车。

你可以说：

- "画一个恐龙的家"
- "生成一个运营数据看板"
- "给页面加一个订单数据表"

然后电脑就会像画画一样，一点一点把页面变出来。别急，等它画完。

**小秘密：** 你还可以点右边的 **添加参考图**，把一张你喜欢的图片给电脑看，它会更明白你想要什么。

### 电脑说"改好了"，还没算数！

画完以后，电脑会举起一张小卡片问你："这样改可以吗？"

- 觉得好看 → 点 **应用变更**，就真的画上去啦。
- 觉得不对 → 点 **取消**，跟没画过一样，什么都不会变坏。

---

## 四、自己动手改

### 把零件放上画纸

左边的格子里有好多零件（按钮、图片、表格……），点一个，它就放到你的画里了。

想换零件？点中间画纸上的东西，它会亮起来，就像你用手捏住了它，可以拖到你喜欢的位置。

### 改零件的样子

捏住一个零件后，看右边：

- 想改上面写的字？在右边格子里的框框改。
- 想换颜色？右边有专门管颜色的地方。

改一个地方，画纸马上就变。

### 说悄悄话改一点点

不用整页重画！先捏住一个零件，再对下面的输入框小声说：

- "只改这个区块的间距"
- "换成警告色强调"

电脑就只改你捏住的那一个，别的都不动。

---

## 五、做错了怎么办？橡皮擦！

- 按 **Ctrl + Z**（按住 Ctrl 不放，再按一下 Z）→ 退一步。
- 按 **Ctrl + Shift + Z** → 又往前走一步（不小心擦多了，把它变回来）。

在画纸上拖东西拖到一半不想拖了？按一下键盘左上角的 **Esc**（写着 Esc 的键），它会自己弹回原来的地方，假装什么都没发生。

---

## 六、存钱罐——保存你的画

画好的东西要存起来，不然关掉电脑就飞走啦！

- 按 **Ctrl + S** → 存进去！
- 存好以后，上面会亮起 **已保存**。
- 如果显示 **未保存更改**，就是提醒你："还没存哦！"

**真话：** 没存就想关掉网页的时候，电脑会拦住你问"确定吗？"——这时候喊大人来看一眼，别乱点。

### 存很多份（像给画拍照）

右边有 **版本** 的格子：

- 点一下给它起名字，就像给这幅画拍一张照片存起来。
- 以后画坏了，回来点那张"照片"，就能变回当时的样子。
- 照片最多存 50 张，太老的会自动扔掉，所以最新的那几张最保险。

---

## 七、把画带回家

想把你的画变成真的网页送给别人看？

1. 点 **生成代码**，电脑把你的画翻译成电脑才懂的字。
2. 点 **导出 zip**，得到一个压缩包——这就是你的作品，可以拿去给别人装到他们的电脑上跑起来！

---

## 八、魔法咒语清单（给大人看的备忘）

| 咒语 | 干什么 |
| --- | --- |
| Ctrl + S | 保存 |
| Ctrl + K | 打开命令面板（什么都能搜到） |
| Ctrl + Z | 撤销一步 |
| Ctrl + Shift + Z | 重做一步 |
| Esc | 取消正在拖的东西 |

---

## 九、记住三件事

1. **捏住它再说话** —— 想只改一个东西，先点选中它，再说悄悄话。
2. **好看才点应用变更** —— 电脑的卡片没点确认前，画纸是不会变的。
3. **画完要 Ctrl + S** —— 像把玩具收回盒子，不然会丢。

玩得开心！🦖
