# Local AI UI Studio 深色界面设计规范

版本：v1.0 · 日期：2026-09-09 · 状态：**历史方案（已被后续 chrome 重做覆盖）**
配套：`apps/workbench/src/index.css`（以当前 @theme 令牌与组件类名为准）

> **接手核对（2026-09）**：本文档描述早期「专业深色工具风」方案。其后 workbench chrome 又经历 Linear 浅色与 Figma 编辑器风重做。本文档仍可作深色令牌/对比度/密度参考；**不要**直接按第 6 节去覆盖现有 chrome。

## 1. 设计定位与原则

本方案为工作台引入**专业深色工具风**（VS Code / Linear Dark 一脉），在现有浅色令牌体系之上以 `[data-theme="dark"]` 叠加实现，品牌紫 `#5E6AD2` 保持不变，保证亮暗两版的品牌连续性。

五条原则：

1. **分层代替阴影**：深色模式禁用投影堆叠，用五级表面灰阶 + 1px hairline 表达层级。
2. **画布聚焦**：工作台 chrome 深色，中央预览画布保持浅色底，被设计的对象成为唯一亮区（Figma 式注意力模型）。
3. **专业密度**：正文基准 13px，控件高度 28px，行高 1.6；信息密度优先于留白，但不低于 11px 最小字号。
4. **单一强调色**：品牌紫是界面中唯一的"非灰"常驻色；语义色只出现在状态语义处（状态点、徽章、Diff）。
5. **无障碍内建**：所有文字对比度满足 WCAG AA（正文 ≥ 4.5:1），全键盘可达，`prefers-reduced-motion` 全局降级。

## 2. 设计令牌（Dark Theme）

以下令牌以 CSS variables 形式给出，直接并入 `@theme` 的 dark 作用域。

### 2.1 表面（由深到浅）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--color-bg-app` | `#0F1115` | 应用最底、底部 Dock |
| `--color-bg-panel` | `#15181D` | 左右侧栏、顶栏 |
| `--color-bg-canvas` | `#1B1F26` | 中央画布区、卡片 |
| `--color-bg-raised` | `#22262E` | 输入框、分段控件、用户消息气泡 |
| `--color-bg-hover` | `#2A2F38` | 悬浮态、分段选中项 |

### 2.2 文字

| 令牌 | 值 | 对比（vs #15181D） | 用途 |
| --- | --- | --- | --- |
| `--color-text-primary` | `#E9EBEE` | 15.2:1 | 标题、正文主体 |
| `--color-text-secondary` | `#ADB4BF` | 8.3:1 | 次要说明、属性值 |
| `--color-text-muted` | `#7E8794` | 4.7:1 | 分组标签、辅助文字 |
| `--color-text-faint` | `#525A66` | 装饰性 | 占位符、禁用态（不承载信息） |

### 2.3 边框

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--color-hairline` | `#262B33` | 面板分隔线 |
| `--color-hairline-strong` | `#333944` | 控件描边 |
| `--color-hairline-emphasis` | `#404754` | 悬浮描边 |

### 2.4 品牌强调

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--color-accent` | `#5E6AD2` | 主按钮底、选中描边（白字 4.7:1） |
| `--color-accent-hover` | `#6A75DE` | 主按钮悬浮 |
| `--color-accent-pressed` | `#4048A8` | 主按钮按下 |
| `--color-accent-text` | `#7B87E8` | 深底上的强调文字/图标/焦点圈（5.7:1） |
| `--color-accent-soft` | `#232741` | 选中行底、品牌徽章底 |

### 2.5 语义色

| 语义 | 主色 | 叠加底（12%） | 用途 |
| --- | --- | --- | --- |
| 成功 | `#34D399` | `#14231C` | 通过状态、Diff 新增行 |
| 警告 | `#FBBF24` | `#2B2415` | 截图问题、生成中 |
| 危险 | `#F87171` | `#2E1D1D` | 错误、Diff 删除行、回退 |
| 信息 | `#60A5FA` | `#16233A` | 提示类徽章 |

### 2.6 字体

- 字族不变：系统栈 sans + 等宽（`ui-monospace, Cascadia Code, Consolas`），离线约束优先。
- 字号阶梯：`20 / 16 / 14 / 13（基准）/ 12`，代码与节点 ID 一律等宽。
- 字重只用 400 / 500 两档。

### 2.7 间距、圆角、动效

- 间距：4px 基准，`4 / 8 / 12 / 16 / 24 / 32`；面板内边距 12，卡片 16，分区 24。
- 圆角：控件 6，卡片/面板内卡片 8，弹窗 12（延续浅色版四级体系）。
- 动效：`120ms`（控件态）/ `160ms`（面板）/ `240ms`（弹窗）；深色模式不加发光动画。

## 3. 布局规范

```text
┌──────────────────────────────────────────────────────┐
│ 顶栏 44px：logo · 项目名 · 版本 | 视口切换 · 撤销重做 · 截图 · 导出 │
├───────────┬──────────────────────────┬───────────────┤
│ 左栏 260   │ 中央画布（flex）           │ 右栏 240       │
│ (min 220) │  工具行 32：缩放 · 视口尺寸  │ (min 200)     │
│ 需求/对话/ │  浅色预览页面 + 选中态       │ 图层/属性/Token│
│ 历史       │                          │               │
├───────────┴──────────────────────────┴───────────────┤
│ 底部 Dock（可折叠 32 ↔ 160）：Diff · 日志 · 截图 · 版本  │
└──────────────────────────────────────────────────────┘
```

- 顶栏高 44px；左右栏默认 260 / 240，可拖拽 220-380；底部 Dock 默认 160px，双击标签折叠为 32px。
- 标签页激活态：文字 `text-primary` + 2px 品牌色下划线；非激活 `text-muted`。
- 深色 chrome 包裹浅色画布（`#FAFAFB` 页面底 + `#333944` 描边 + 6px 圆角），画布内生成的页面始终按用户项目 Token 渲染，不跟随工作台主题。

## 4. 核心组件规范

### 4.1 按钮

- 高 28px，内边距 `4 12`，圆角 6，字号 13。
- 主要（品牌底白字，每屏至多 1 个）/ 次要（描边）/ 幽灵（纯文字）/ 危险（danger 12% 底 + danger 文字）/ 禁用（opacity 0.45 + pointer-events none）。
- 焦点：`outline: 2px solid #7B87E8; outline-offset: 2px`。

### 4.2 输入

- 底 `bg-raised`，描边 `hairline-strong`，高 28px。
- 焦点 = 品牌色描边 + `0 0 0 3px rgba(94,106,210,0.3)` 光晕（唯一允许的投影）。
- 占位符 `text-faint`，仅为装饰性提示。

### 4.3 选中态（画布内元素）

- 选中：2px 品牌描边 + 4 个白底角手柄（5px）+ 节点 ID 标签（品牌底白字，等宽字体）。
- 悬停预选：1px 品牌色虚线描边。
- 图层树选中行：`accent-soft` 底 + `#A5ACF0` 文字。

### 4.4 徽章与状态

- 语义徽章 = 语义色 12% 叠加底 + 原色文字；中性徽章 = `bg-raised` + `text-secondary`。
- 状态点：7px 圆点 + `text-secondary` 文字。
- Diff 行：新增 = success 10% 底绿字；删除 = danger 10% 底红字。

### 4.5 变更计划卡片（AI 确认流）

- 卡片底 `bg-canvas`，描边 `hairline-strong`，圆角 8。
- 结构：标题（节点 ID 等宽）+ Diff 统计（`+n −n` 等宽绿/红）→ 变更列表 → 操作行（主要"确认应用" + 幽灵"取消"）。
- 任何超出目标节点范围的修改必须被拦截，卡片内显示"超范围修改已阻止"警告徽章。

## 5. 无障碍标准（WCAG AA）

- 对比度：正文与界面文字 ≥ 4.5:1（已在令牌层逐项校验，见 2.2 / 2.4）；`text-faint` 仅用于不承载信息的占位/禁用。
- 键盘：Tab 顺序 = 顶栏 → 左栏 → 画布（图层可上下导航）→ 右栏 → Dock；焦点圈统一 2px `#7B87E8`。
- 焦点不可被移除，仅可用 `:focus-visible` 控制显示。
- `prefers-reduced-motion: reduce` 时关闭全部过渡与动画（沿用现有实现）。
- 屏幕阅读器：面板使用 `role="region"` + `aria-label`；Dock 标签实现 `role="tablist"`（现有 `dock-a11y.test.tsx` 覆盖）。

## 6. 落地步骤

1. 在 `index.css` 的 `@theme` 外增加 `[data-theme="dark"]` 作用域，映射 2.x 全部令牌；`html` 元素加 `color-scheme: dark`。
2. 顶栏增加主题切换（浅色 / 深色 / 跟随系统），写入项目设置持久化。
3. 逐面板替换硬编码颜色为语义令牌（优先级：TopBar → 三栏 → Dock → 弹窗）。
4. Monaco、iframe 预览外围描边同步换用 `hairline-strong`。
5. 为对比度与主题切换补充组件测试（`theme-switch.test.tsx`）。

## 7. 验收清单

- [ ] 深色模式下全部界面文字对比度 ≥ 4.5:1（`text-faint` 除外）
- [ ] 界面无常驻非灰非常驻色（品牌紫 + 语义色除外）
- [ ] 选中/悬停/焦点/禁用四态在所有交互组件上齐全
- [ ] 画布预览不随工作台主题变化，按项目 Token 渲染
- [ ] 主题切换即时生效且刷新后保持
- [ ] `prefers-reduced-motion` 下无动画
